# P1 — проверка минимального Telegram-бота

**Дата:** 10 ноября 2026 года. **Ветка:** `main`.

Код P1: `src/tgbot/config.py`, `storage.py`, `llm.py`, `telegram.py`, `main.py`; пример окружения, зависимости, запуск на Windows, проверки.

**Маршрут:** Telegram long polling → обработчик личного текста → уникальная запись SQLite → контекст текущего личного чата → HTTP `/chat/completions` → запись `pending` → `send_message` → `sent` с настоящим идентификатором Telegram либо `failed`/`unknown`.

**Проверки:** локальные проверки без сетевых ключей и GitHub Actions предназначены для подтверждения хранения, дедупликации, API-контракта, обработки ошибок и сценария с имитацией транспорта. Локально: `compileall` прошёл, 16 проверок `unittest` прошли; для импорта `aiogram.exceptions` использована временная локальная заглушка, поскольку пакет не установлен в данной среде. **Это не реальная проверка Telegram.** Итоги CI будут приведены отдельно после завершения workflow.

**НЕ ПРОВЕРЕНО:** живое сообщение реального Telegram-бота, осмысленность реального ответа LLM, реальные ошибки авторизации провайдера, доставка ответа до экрана пользователя, корректность остановки на локальном Windows ПК. Токены и ключи в GitHub не загружены.

**Ограничения P1:** только личный текст; новая отправка после неизвестного сетевого исхода не повторяется автоматически во избежание дублей; незавершённые входящие после внезапного завершения процесса остаются в SQLite, но автоматически не переотправляются. Это не подтверждённая эксплуатационная готовность.

**Предварительное решение:** P1 завершена частично, пока живая приёмка не проведена.
